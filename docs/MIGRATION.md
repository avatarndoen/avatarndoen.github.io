# Content provenance

The engineering portfolio was assembled from the owner's portfolio documents, project media, and subsequent technical revisions. Editable content is maintained in the current Markdown files and project folders; earlier source documents are not required for normal site generation.

## Figures and media

Project image metadata records descriptive text and, where available, source-document references. [`WORD IMAGE UPGRADES.json`](WORD%20IMAGE%20UPGRADES.json) tracks verified image replacements and hashes used by the repository checks.

Video records retain the demonstration URLs in their project folders. Embedded videos are hosted externally; the presence of a video does not independently establish measured accuracy or performance.

## Technical descriptions

Project pages distinguish design work, prototype demonstrations, reported observations, and future development directions. Where further closed-loop control or integration is described under “What Is Next?”, it is presented as a planned direction, not a completed result.

The downloadable portfolio PDF and CV are maintained separately from the editable website and may not reflect every recent website update.
